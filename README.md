# Nook

Nook 是一个运行在 OpenWrt/ImmortalWrt 路由器上的局域网协作小站。

它不依赖公网账号，也不需要外部服务器。只要设备连接到同一个局域网，打开路由器上的 Nook 页面，就可以在附近设备之间共享文本、发布文件、领取文件或直接传输文件。

## 适合做什么

- 在手机、电脑、平板之间临时传文件
- 在办公室把大文件临时发布给同事领取
- 把一段文字、链接或消息快速同步给局域网内的设备
- 在家里、办公室、宿舍等局域网环境中搭建一个轻量协作入口
- 让路由器成为一个随时可用的本地共享空间

## 当前功能

- 局域网设备自动发现
- 在线设备列表
- 设备名称自定义
- 设备名记忆与重置
- 共享剪贴板
- 直接文本发送
- 直接文件发送
- 文件公告板
- 多文件发布
- 其他设备点击领取文件
- 发布者撤回或清空自己的文件公告
- 页面显示当前版本号
- 浏览器直接使用，无需安装客户端

## 文件传输方式

Nook 默认不把文件存到路由器上。

文件公告板只会在路由器内存中保存文件名、大小、发布者、发布时间等元信息。真正的文件内容仍保留在发布者浏览器中，其他设备点击领取时，通过 WebRTC DataChannel 尽量在设备之间点对点传输。

这意味着：

- 发布者页面需要保持打开。
- 发布者设备需要保持在线。
- 发布者刷新页面或关闭浏览器后，相关文件公告会失效。
- 路由器不会持久保存文件内容。

## 使用方式

安装并启动 Nook 后，在同一局域网内访问：

```text
http://路由器地址:8088
```

例如：

```text
http://192.168.1.1:8088
```

打开页面后：

1. 给当前设备设置一个容易识别的名字。
2. 如需保留设备名，勾选 `Remember`。
3. 在共享剪贴板中发布文字或链接。
4. 在文件公告板中发布文件，其他设备可以点击领取。
5. 也可以点击在线设备，直接发送文本或文件。

## 安装包

Nook 为 OpenWrt/ImmortalWrt 提供 aarch64（arm64）和 x86_64 两种架构的安装包，每种架构各含 ipk 和 apk 格式。发布时使用 `v` 开头的 Git tag 作为版本号，例如 `v0.1.6` 会生成：

```text
nook_0.1.6-1_aarch64_cortex-a53.ipk
nook_0.1.6-1_x86_64.ipk
nook_0.1.6-r1_aarch64_cortex-a53.apk
nook_0.1.6-r1_x86_64.apk
```

使用 opkg 安装（按设备架构选择对应包）：

```sh
opkg install ./nook_0.1.6-1_aarch64_cortex-a53.ipk
```

使用 apk 包管理器安装未签名本地包时，通常需要允许不受信任的本地包：

```sh
apk add --allow-untrusted ./nook_0.1.6-r1_aarch64_cortex-a53.apk
```

## 安装和升级行为

- 首次安装后不会自动启动服务。
- 如果升级时 `nook` 服务正在运行，安装完成后会自动重启服务。
- 如果升级前服务没有运行，安装完成后不会自动启动。

## OpenWrt 服务

默认监听地址：

```text
0.0.0.0:8088
```

服务名称：

```text
nook
```

常用命令：

```sh
/etc/init.d/nook enable
/etc/init.d/nook start
/etc/init.d/nook stop
/etc/init.d/nook restart
```

配置文件：

```text
/etc/config/nook
```

## 注意事项

- Nook 面向可信局域网使用。
- 当前版本的剪贴板、在线设备、文件公告都保存在内存中，服务重启后会清空。
- 文件传输能力取决于浏览器、设备性能和局域网环境。
- 如果设备之间无法建立点对点连接，请确认它们位于同一局域网，且浏览器支持 WebRTC。
