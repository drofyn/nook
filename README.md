# Nook

Nook 是一个运行在 OpenWrt/ImmortalWrt 路由器上的局域网协作小站。

它不依赖公网账号，也不需要外部服务器。只要设备连接到同一个局域网，打开路由器上的 Nook 页面，就可以看到附近在线的设备，并在它们之间发送文本或传输文件。

## 适合做什么

- 在手机、电脑、平板之间临时传文件
- 把一段文字、链接或消息快速发给另一台设备
- 在家里、办公室、宿舍等局域网环境中搭建一个轻量协作入口
- 让路由器成为一个随时可用的本地共享空间

## 当前功能

- 局域网设备自动发现
- 在线设备列表
- 设备名称自定义
- 文本发送
- 文件发送
- 浏览器直接使用，无需安装客户端
- 文件传输尽量在设备之间点对点进行，路由器主要负责页面服务和连接协调

## 使用方式

安装并启动 Nook 后，在同一局域网内访问：

```text
http://路由器地址:8088
```

例如：

```text
http://192.168.1.1:8088
```

打开页面后：

1. 给当前设备设置一个容易识别的名字。
2. 等待其他设备出现在列表中。
3. 点击目标设备。
4. 发送文本或选择文件发送。

## 安装包

Nook 提供两种 OpenWrt/ImmortalWrt 安装包。发布时使用 `v` 开头的 Git tag 作为版本号，例如 `v0.1.0` 会生成：

```text
nook_<版本号>-1_aarch64_cortex-a53.ipk
nook_<版本号>-r1_aarch64_cortex-a53.apk
```

如果使用 apk 包管理器安装未签名本地包，通常需要允许不受信任的本地包：

```sh
apk add --allow-untrusted ./nook_<版本号>-r1_aarch64_cortex-a53.apk
```

## OpenWrt 服务

默认监听地址：

```text
0.0.0.0:8088
```

服务名称：

```text
nook
```

常用命令：

```sh
/etc/init.d/nook enable
/etc/init.d/nook start
/etc/init.d/nook stop
/etc/init.d/nook restart
```

配置文件：

```text
/etc/config/nook
```

## 注意事项

- Nook 面向可信局域网使用。
- 当前版本的数据不会持久保存，刷新页面或断开连接后，临时状态可能丢失。
- 文件传输能力取决于浏览器、设备性能和局域网环境。
- 如果设备之间无法建立点对点连接，请确认它们位于同一局域网，且浏览器支持 WebRTC。
